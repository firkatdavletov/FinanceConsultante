# Валюта бюджета в Firebase API v4

Поддерживаемые валюты бюджета — KZT, RUB, USD, EUR. Android явно отправляет выбранное
значение при создании. Для старых запросов без валюты и существующих бюджетов
используется KZT. При импорте валюта передаётся в исходном bootstrap.

`PATCH /api/v4/budgets/{budgetId}` принимает `requestId` и хотя бы одно из полей
`name` или `currency`. Изменение доступно активному OWNER. Повтор принятого запроса
возвращает актуальное состояние. Изменение payload при том же requestId даёт 409.

Каталог, создание, подключение и область финансового обмена возвращают `currency` и
`currencyVersion`. Версия увеличивается при фактическом изменении валюты. Миграция V34
журналирует изменение и повторно публикует исторические проводки с курсом RUB/KZT,
чтобы уже подключённые устройства получили `rubKztRate`.

Учётные числа при смене валюты сохраняются. Столбцы и поля v4 с историческим именем
`amountKzt` несут учётную сумму бюджета. Для старых RUB-проводок отдельно передаются
оригинальная сумма и курс. Прежние fingerprints и receipts остаются действительными.

Выпускать сначала сервер с V34, затем обновлять Android у всех участников бюджета.
