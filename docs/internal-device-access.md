# Доступ к облачным функциям Saldomi

В актуальном Android-клиенте Boolean-параметр Firebase Remote Config
`remote_access` определяет видимость облачных функций. Для защищённых запросов
FinanceConsultante проверяет Firebase-токен, активное членство и роль в бюджете.
Регистрация UUID установки для облачных запросов больше не требуется.

## Совместимость

`GET /api/v4/app/access` отвечает `200 OK`, `Cache-Control: no-store` и
`{"mode":"OFFLINE_FREE"}` при любом `X-Device-Id`, в том числе без заголовка.
Старый Android-клиент с локальным разрешением переходит в локальный режим после
следующей успешной проверки. Миграция V35, таблица `internal_app_installation`
и существующие данные сохраняются.

## Выпуск

1. В Firebase Console подготовить Boolean-параметр `remote_access` со значением
   по умолчанию `false` и условиями `true` для нужных установок.
2. Выпустить FinanceConsultante с совместимым endpoint. Удалить устаревшую
   переменную `INTERNAL_DEVICE_GATE_ENABLED` из конфигурации развёртывания.
3. Выпустить Android-клиент и проверить облачный доступ на установке из целевой
   группы и локальный режим на установке вне неё.
